A single funny line for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) bounty on make.fun.

## How it works

Run `main.py` and it writes one comedy one-liner to `/output/entry.txt`:

```sh
python3 main.py
```

The line:

> I finally achieved work-life balance: I now panic about work from home and panic about life from the office.

It is a single line, well inside the 280 character gate.
